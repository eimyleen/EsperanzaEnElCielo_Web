
# Esperanza en el Cielo - Wiki

Wiki del videojuego **Esperanza en el Cielo**, desarrollada como una aplicación web progresiva (PWA) utilizando React y Vite.

Este sitio permite conocer la historia, los personajes, los niveles, los objetos y las mecánicas del videojuego.

## Descripción del videojuego

**Esperanza en el Cielo** es un videojuego 2D de acción, plataformas, supervivencia y ciencia ficción, desarrollado en Unity.

La historia sigue al doctor Mateo, un científico universitario que debe sobrevivir en una Tierra devastada por una misteriosa infección que ha transformado a las personas en criaturas peligrosas.

Mientras la humanidad evacúa el planeta, Mateo deberá atravesar diferentes escenarios, enfrentarse a criaturas infectadas y utilizar un traje experimental capaz de aprovechar la energía de unas gemas especiales.

Su objetivo principal es llegar hasta la última nave de evacuación antes de que sea demasiado tarde.

## Secciones de la wiki

La aplicación cuenta con cinco secciones principales.

### 1. Inicio

Presenta una bienvenida del doctor Mateo e información general del videojuego.

Incluye:

- Introducción al proyecto.
- Historia del videojuego.
- Objetivo principal.
- Género y características de la aventura.

### 2. Personajes

Presenta información sobre los protagonistas, aliados y enemigos del videojuego.

Personajes incluidos:

- Doctor Mateo.
- El Sargento.
- Maniquí de entrenamiento.
- Infectado común.
- Infectado rastrero.
- Infectado grande.
- El Recolector, jefe final.

Cada personaje cuenta con una ilustración, descripción y características principales.

### 3. Niveles

Describe los escenarios que Mateo deberá atravesar durante su aventura.

Los cuatro escenarios son:

1. **Laboratorio:** tutorial y entrenamiento.
2. **Ciudad infectada:** exploración y supervivencia.
3. **Torre orbital:** tecnología y sistemas de seguridad.
4. **Reactor:** enfrentamiento contra el jefe final.

Cada nivel incluye:

- Descripción del escenario.
- Historia.
- Objetivo.
- Elementos principales.
- Enemigos.
- Ilustración del escenario.

### 4. Objetos

Muestra los objetos y herramientas disponibles durante el videojuego.

Incluye:

- Pistola de pulso.
- Gema verde.
- Gema roja.
- Gema azul.
- Venda.
- Botiquín.

Las gemas permiten obtener habilidades especiales, mientras que los objetos médicos ayudan a recuperar salud.

### 5. Mecánicas

Explica el funcionamiento general del videojuego.

Incluye:

- Instrucciones para jugar.
- Controles provisionales.
- Movimiento y plataformas.
- Combate.

- Curación.
- Exploración.
- Habilidades del traje experimental.

## Funcionalidades de la PWA

La wiki está configurada como una Progressive Web App (PWA).

### Instalación

La aplicación puede instalarse desde navegadores compatibles en computadoras y dispositivos móviles.

Una vez instalada, puede abrirse desde el escritorio o la pantalla de inicio del dispositivo, dependiendo del sistema operativo.

### Funcionamiento sin conexión

La aplicación utiliza un Service Worker para almacenar los archivos esenciales.

Cuando el dispositivo no tiene conexión a internet:

- Las cinco secciones continúan disponibles.
- Los textos permanecen visibles.
- El fondo principal y el logo siguen mostrándose.
- Las demás ilustraciones son sustituidas por un mensaje de imagen no disponible.

Cuando se recupera la conexión, las ilustraciones vuelven a mostrarse.

Es necesario haber abierto la aplicación previamente con conexión para que los recursos esenciales queden almacenados.

### Diseño responsive

La interfaz está adaptada para:

- Computadoras.
- Tablets.
- Teléfonos celulares.

La wiki cuenta con navegación adaptable, tarjetas informativas e ilustraciones que se ajustan a diferentes tamaños de pantalla.

## Requisitos del videojuego

**Esperanza en el Cielo** es un videojuego 2D desarrollado con Unity y pensado inicialmente para computadoras con Windows.

Los requisitos presentados a continuación son estimaciones provisionales. No representan especificaciones definitivas ni garantizan un rendimiento determinado.

Se actualizarán cuando exista una versión ejecutable del videojuego y se realicen pruebas de rendimiento.

### Requisitos mínimos estimados

| Componente | Requisito |
|---|---|
| Sistema operativo | Windows 10 de 64 bits |
| Procesador | Intel Core i3 o AMD equivalente |
| Memoria RAM | 4 GB |
| Tarjeta gráfica | Gráficos integrados compatibles con DirectX 11 |
| Almacenamiento | Espacio requerido por definir |
| Periféricos | Teclado y mouse |
| Conexión a internet | No prevista como necesaria para jugar |

### Requisitos recomendados estimados

| Componente | Requisito |
|---|---|
| Sistema operativo | Windows 10 u 11 de 64 bits |
| Procesador | Intel Core i5 o AMD Ryzen 5 |
| Memoria RAM | 8 GB |
| Tarjeta gráfica | Gráficos integrados modernos o GPU dedicada compatible con DirectX 11 |
| Almacenamiento | Espacio requerido por definir |
| Periféricos | Teclado y mouse |
| Conexión a internet | Para descargar el juego y sus actualizaciones |

**Nota:** Las especificaciones anteriores están sujetas a cambios según la optimización, las características y los resultados de las pruebas del videojuego.

### Instalación del videojuego

Cuando esté disponible una versión ejecutable para Windows, el procedimiento previsto será:

1. Descargar el videojuego desde el enlace oficial de distribución.
2. Extraer los archivos si se proporciona un archivo comprimido `.zip`.
3. Abrir la carpeta del videojuego.
4. Mantener juntos el archivo ejecutable y sus carpetas de datos.
5. Ejecutar el archivo `.exe` del videojuego.
6. Configurar los controles y comenzar a jugar.

**Estado de distribución:** El videojuego se encuentra en desarrollo. Todavía no se incluye un enlace de descarga de una versión final.

## Instalación y ejecución local de la wiki

Para ejecutar el proyecto web localmente, se necesita:

- Node.js en una versión compatible con Vite.
- npm.
- Git.
- Un navegador web moderno.

### 1. Clonar el repositorio

```bash
git clone https://github.com/eimyleen/EsperanzaEnElCielo_Web.git
```

### 2. Entrar al proyecto

```bash
cd EsperanzaEnElCielo_Web
```

### 3. Instalar las dependencias

```bash
npm install
```

### 4. Iniciar el servidor de desarrollo

```bash
npm run dev
```

Abrir la dirección indicada por Vite, normalmente:

http://localhost:5173

---

## Compilación de producción

Para generar la versión optimizada de la wiki:

```bash
npm run build
```

Para probar localmente la versión compilada:

```bash
npm run preview
```

Normalmente estará disponible en:

http://localhost:4173

La compilación genera una carpeta llamada `dist`, que contiene los archivos necesarios para publicar la aplicación.

El Service Worker de producción permite probar las funcionalidades PWA, incluyendo el funcionamiento sin conexión.
